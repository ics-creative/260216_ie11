# IE11時代コーディング サンプル集

記事「君はIE11を覚えているか？ 2010年代のHTMLコーディングを振り返る」向けのデモです。

## 使い方

1. ブラウザで `/Users/ikeda/Documents/git/260216_ie11/index.html` を開きます。
2. `fetch` 代替（`XMLHttpRequest`）のデモを動かす場合は、`http` / `https` 経由でアクセスしてください。

## 含まれるデモ

- `Flexbox`
- `object-fit` の代替（背景画像）
- `aspect-ratio` の代替（`padding-top`）
- `position: sticky` の代替（スクロール監視 + `is-fixed` 切り替え）
- `loading="lazy"` の代替（手動 lazy load）
- `classList.toggle(name, force)` の代替（`add` / `remove`）
- `fetch()` の代替（`XMLHttpRequest`）
- `details/summary` の代替（`div + div`）
- `X-UA-Compatible` の例
